How it works

Claude's 5-hour clock starts at your first message. So send it at 6.

The window is rolling. It starts with the first request and resets five hours later, however much you used. If that first request is a two-word greeting fired by launchd at dawn, the reset moves three hours earlier.

The menu bar app

Your limit, always in view.

AutowakeBar is a single Swift file that lives in your menu bar. It reads the same usage numbers as Claude Code's /usage, using the login already in your Keychain.

  • 5-hour usage and time to reset right in the menu bar, turning orange at 70% and red at 90%.
  • 7-day usage, so the weekly cap doesn't sneak up on you on a Thursday.
  • Health checks for the launchd agents, plus your next ping and how the last one went.
  • Ping now for the days you're up before the sun.

Token stats

Find out where the tokens went.

Press ⌘T and get a breakdown of the current window, today, the last 24 hours or the week, read straight from Claude Code's local transcripts. Nothing leaves your machine. "Weighted" counts tokens at their price ratio, so the 700M cache reads stop hiding the session that actually ate your limit.

Install

Four commands. No DMG.

Pavel asked for a DMG. There's a build.sh instead. It compiles in about three seconds, and you get to read what you're running.

Clone it

Everything lives in a handful of shell scripts and one Swift file.

git clone https://github.com/adrians5j/claude-autowake.git cd claude-autowake

Pick your times

Set PING_TIMES in config.sh. Keep them at least 5 hours apart.

# config.sh PING_TIMES=("06:00" "11:05" "16:10")

Install the schedule

Sets up the launchd agents and a pmset wake. Asks for sudo once.

./install.sh ./status.sh

Add the menu bar app

Optional, but it's the fun part. Starts at login.

./menubar/build.sh --install

You'll need macOS 13+, Claude Code installed and logged in, and the Xcode command line tools (xcode-select --install). Keep the Mac plugged in overnight so it can wake itself. Changed config.sh later? Run ./install.sh again; the schedule is baked in at install time.

FAQ

Where's the DMG?

There isn't one. Unsigned apps from strangers on the internet make macOS nervous, and Gatekeeper is right to be. ./menubar/build.sh builds it locally with swiftc in a few seconds, from source you can read in one sitting.

Was this really vibe-coded?

Yes. The menu bar app, the token stats window and this website were each about one prompt to Claude Code, plus some light heckling in Slack. The original autowake scripts are by Luca Lapenna; this fork added the app.

Does pinging Haiku cost anything?

One short greeting to the smallest model, a few times a day. It barely registers on the usage meter. It counts against your subscription like any other message, and nothing is billed separately.

What if my Mac is asleep at 6?

The installer schedules a pmset wake a few minutes before the first ping, and a caffeinate agent keeps the Mac awake until the last ping of the day. It has to be plugged in for the wake to fire.

Is this against the rules?

It sends a normal message from your own Claude Code login, on your own machine, at a time you picked. That's the same as typing "hi" at 6am, just with less suffering. Not affiliated with Anthropic.

Windows? Linux?

No. It's built on launchd, pmset and caffeinate. A cron job with the same claude -p "hi" line gets you most of the way, if you want to vibe-code the port yourself.
